# 👁️ Sentry зрение

Sentry зрение это проект в области компьютерного зрения, использующий **YOLOv8**, **OpenCV** и **Pygame** для обнаружения объектов в реальном времени через веб-камеру и отправки оповещений при обнаружении определённых объектов.

![SentryVisionDemo](https://github.com/KrishBharadwaj5678/SentryVision/blob/main/SentryVisionDemo.jpg)

## 🚀 Возможности

| Функция                                     | Описание                                               |
| ------------------------------------------- | ------------------------------------------------------ |
| 🎯 Обнаружение объектов в реальном времени  | Использует YOLOv8 для мгновенного обнаружения объектов |
| 📷 Мониторинг веб-камеры                    | Обрабатывает видеопоток с помощью OpenCV               |
| 🔔 Система звуковых оповещений              | Воспроизводит звук при обнаружении целевого объекта    |
| 🖼️ Сохранение доказательств                | Автоматически сохраняет аннотированные изображения     |
| 📧 Система уведомлений по электронной почте | Отправляет уведомления с прикреплёнными изображениями  |
| ⚡ Лёгкая производительность                 | Оптимизировано для работы в реальном времени           |

## 🛠️ Технологии

| Технология              | Описание                                           |
| ----------------------- | -------------------------------------------------- |
| 🐍 Питон              | Основной язык программирования                     |
| 🧠 YOLOv8 (Ультралитики) | Модель глубокого обучения для обнаружения объектов |

## ⚙️ Установка

### 1️⃣ Клонируйте репозиторий

```bash id="9v3rxt"
git clone https://github.com/KrishBharadwaj5678/SentryVision.git
```

### 2️⃣ Перейдите в папку проекта

```bash id="1p4nzy"
cd SentryVision
```

### 3️⃣ Настройте переменные окружения

Создайте файл `.env` в корневой директории проекта:

```env id="4m8kws"
SENDER_EMAIL=email отправителя
RECEIVER_EMAIL=email получателя
EMAIL_PASS=пароль приложения
```

### 4️⃣ Установите зависимости

```bash id="7f2xqd"
pip install -r requirements.txt
```

### 5️⃣ Запустите проект

```bash id="3c9lva"
python app.py
```
